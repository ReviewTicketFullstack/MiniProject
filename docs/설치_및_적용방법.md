# Minutely 설치 및 적용 방법

## 1. 사전 요구사항

- **Notion MCP 커넥터 연결** (필수) — 경로 A/B 모두 Notion 읽기·쓰기에 필요.
- **Python 3** — diff/전사 스크립트 실행 (외부 패키지 불필요, 표준 라이브러리만).
- **경로 B 음성만**: `OPENAI_API_KEY` + `ffmpeg`. (텍스트 파일 입력은 둘 다 불필요.)

## 2. 설치 (로컬)

이 저장소를 로컬 마켓플레이스로 등록해 설치한다. **터미널에서** 실행:

```bash
claude plugin marketplace add "C:\Users\Har24\Desktop\Project\MiniProject\Minutely"
```

```bash
claude plugin install minutely@minutely
```

설치 후 **세션을 재시작**하면 `/minutely` 커맨드와 자연어 트리거가 활성화된다.

확인:

```bash
claude plugin list
```

> 대화형 방식: 대화형 `claude` 세션에서 `/plugin` → Add marketplace(위 경로) → Install `minutely`.

## 3. Notion MCP 커넥터

연결이 안 되어 있으면 `/minutely`가 `notion-fetch id:"self"`로 감지해 연결을 안내하고 중단한다.
claude.ai 커넥터 설정 또는 대화형 세션의 `/mcp`에서 Notion을 연결한 뒤 **세션 재시작**한다.

## 4. 음성 기능 설정 (경로 B, 선택)

`OPENAI_API_KEY`를 아래 중 한 곳에 둔다 (환경변수 우선):

- 환경변수 `OPENAI_API_KEY`
- 프로젝트 루트 `.env` (git에서 제외됨)
- `~/.config/minutely/.env`

`.env` 예:

```
OPENAI_API_KEY=sk-...
```

`ffmpeg`가 PATH에 있어야 한다. 없으면 음성 경로만 안내 후 중단된다(다른 기능은 정상).

## 5. 사용법

```bash
/minutely
```
→ 경로 A. C조_한컴 변화(소스 DB + 산문)를 감지해 "노션 변경 내용 정리 (Claude 전용)" 페이지에 로그 append.

```bash
/minutely meeting 회의녹음.m4a
```
→ 경로 B. 전사 → 회의록 양식 요약 → 회의록 DB 새 행.

```bash
/minutely meeting 회의메모.txt
```
→ 경로 B. 텍스트 파일을 그대로 읽어 회의록 작성.

자연어로도 트리거된다: "노션 정리", "노션 변경 정리해줘" (A) / "이 녹음 회의록으로", "회의록 작성" (B).

어느 경로든 **초안을 먼저 보여주고, 승인해야만** Notion에 쓴다.

## 6. 첫 실행 동작

경로 A 최초 실행은 비교할 기준선이 없으므로 **baseline만 생성**하고
"기준선을 만들었습니다. 다음 실행부터 변화를 정리합니다."로 끝난다 — 정상이다.
이후 Notion을 수정하고 다시 실행하면 그때부터 변경분을 정리한다.

## 7. 상태 파일 (git 제외)

프로젝트 루트 `.minutely/`에 저장된다.

| 파일 | 내용 |
|---|---|
| `snapshot.json` | 마지막으로 본 소스 DB 정규화 콘텐츠 (기준선) |
| `page.txt` | 마지막으로 본 페이지 산문 dump (기준선) |
| `current.json`, `page_new.txt` | 이번 실행 수집분 |

## 8. 문제 해결

| 증상 | 원인 · 조치 |
|---|---|
| `/minutely`가 안 뜸 | 설치 후 세션 재시작 필요. `claude plugin list`로 확인 |
| "커넥터 미연결" 안내 후 중단 | Notion MCP 커넥터 연결 후 세션 재시작 |
| 음성에서 키 오류 | `OPENAI_API_KEY` 설정 확인 (환경변수/.env) |
| 음성에서 ffmpeg 오류 | `ffmpeg` 설치 후 PATH 등록 |
| 매번 "변화 없음" | 최초 실행 baseline 이후부터 감지. 소스 DB/산문을 실제로 바꿔야 diff 발생 |

## 9. 개발 중 수정 반영

플러그인 파일을 고친 뒤:

```bash
claude plugin marketplace update minutely
```

그다음 `claude plugin update minutely` 실행 후 세션 재시작. (source가 로컬 경로라 다시 읽는다.)
