`minutely` 스킬로 정리하세요.

인자: `$ARGUMENTS`

- 인자가 `meeting`으로 시작하면 → **경로 B**: 뒤의 파일(녹음/영상 또는 `.txt`/`.md`)을 전사·요약해
  **회의록 DB에 새 회의록**으로 작성.
- 인자가 `work`로 시작하면 → **경로 C**: GitHub 커밋·PR을 수집해
  **데일리 스크럼 DB에 날짜별 작업 내역 행**으로 추가. 뒤에 `YYYY-MM-DD`를 주면 그 날짜부터,
  없으면 DB의 마지막 기록 다음날부터 오늘까지.
- 인자가 없으면 → **경로 A**: 노션 변화(소스 DB + 페이지 산문)를 감지해
  **"노션 변경 내용 정리 (Claude 전용)" 페이지에 날짜별 로그**로 추가.

세 경로 모두 **초안을 먼저 보여주고, 승인받은 뒤에만** Notion에 씁니다. 자세한 절차는 `minutely` 스킬(SKILL.md).
